# csv2md-wiggum

**Mission:** A small Python command-line tool, csv2md, that converts a CSV file into a GitHub-flavoured Markdown table. Features: read from a file path or stdin, column alignment flags (left, right, center), correct escaping of pipe characters and newlines inside cells, a --no-header option, and clear errors for missing or malformed files. Standard library only (argparse, csv). Include a pytest test suite covering every feature and a README with usage examples.
